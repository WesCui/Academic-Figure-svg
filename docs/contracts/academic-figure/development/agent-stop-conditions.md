# Agent Stop Conditions

Code Agent 遇到以下任一条件必须停止生产并请求确认。

## 仓库状态

- 当前分支与批次 Contract 不一致；
- commit 与批准基线不一致且影响相关代码；
- 工作区已有改动与本批次文件重叠；
- 目标文件不存在或结构与事实报告显著不同。

## 范围变化

- 需要修改未授权目录；
- 需要修改公共 MCP 工具名；
- 需要修改 `SvgDocument`；
- 需要改变 `document.json` 权威模型；
- 需要修改 SVG-Edit；
- 需要新增 workspace；
- 需要新增依赖或更新 lockfile；
- 需要大规模重构才能继续。

## 需求歧义

- PDR、稳定 Contract 和批次 Contract 相互冲突；
- 箭头方向、实体身份或业务语义不明确；
- 自动修复可能改变研究语义；
- 参考图作用范围不明确且会改变实现；
- 用户要求与当前非目标冲突。

## 验证问题

- 指定测试无法运行；
- 测试会产生未授权写入；
- 现有测试失败且无法确认是否由本批次导致；
- 无法证明失败操作不污染正式文档；
- diff 出现未计划文件。

## 安全和数据

- 输入 SVG 含危险内容且现有策略无法处理；
- 需要读取或写入授权路径之外；
- 需要删除或覆盖用户数据；
- 回滚或迁移不可恢复。

停止时必须报告：

1. 已确认事实；
2. 阻塞原因；
3. 受影响文件；
4. 可选方案；
5. 每个方案的范围和风险。
